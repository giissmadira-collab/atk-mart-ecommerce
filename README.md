# ATK Mart - Front-End E-Commerce Sederhana

Proyek praktikum E-Business System Pertemuan 7. Website katalog toko alat tulis (ATK) sederhana menggunakan HTML, CSS, dan JavaScript.

## Fitur
- Halaman beranda dan navigasi
- Katalog produk dengan product card
- Pencarian produk
- Tambah produk ke keranjang
- Ubah jumlah dan hapus produk
- Perhitungan total belanja
- Form checkout dengan validasi dasar
- Simulasi konfirmasi pesanan
- Responsive untuk desktop dan mobile

## Struktur
```
ecommerce-project/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Cara menjalankan
1. Unduh/clone repository.
2. Buka `index.html` di browser (atau gunakan Live Server).
3. Coba pencarian produk, tombol tambah, ubah jumlah, hapus, lalu isi checkout.

## Catatan
Ini adalah front-end demo. Belum menggunakan backend, database, login, atau pembayaran sungguhan. Data cart disimpan sementara selama halaman terbuka.
